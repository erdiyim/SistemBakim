## HOTFİX PROTOKOLÜ (Bug Geldiğinde)

```
1. Issue'yu oku → Tekrarlanabilir mi?
   ├── HAYIR → "Can you provide logs?" etiketi + yanıt
   └── EVET → Devam ↓

2. Ciddiyeti belirle:
   ├── KRİTİK (crash/veri kaybı) → 2 saat içinde fix
   ├── YÜKSEK (modül çalışmıyor) → 24 saat içinde fix
   └── DÜŞÜK (görsel/kozmetik) → Sonraki sürümde fix

3. Fix workflow:
   a. Yeni branch: git checkout -b hotfix/issue-XX
   b. Fix yap + test et (Win10 + Win11)
   c. Commit: "fix: [Module X] description (#XX)"
   d. Tag: git tag v5.0.1
   e. Push: git push origin v5.0.1
   f. CI/CD otomatik build + release
   g. Issue'ya yanıt: "Fixed in v5.0.1 — please update"
   h. Reddit/PH'de güncelleme yorumu yaz

codebase is visible on GitHub. It requires zero internet connection, sends zero
data anywhere, and has zero telemetry. You can audit the source yourself, or
build from source if you prefer:

git clone https://github.com/erdiyim/SistemBakim.git
cd SistemBakim/src
echo "" | powershell -NoProfile -ExecutionPolicy Bypass -File "Build-EXE.ps1"

VirusTotal scan: [link to your VT result]
```

### "Why does SmartScreen warn me?"

```
SmartScreen warns about any app without an EV Code Signing Certificate ($400+/year).
As a free, open-source project, we don't have one — that's the only reason for the
warning. Click "More info" → "Run anyway" to proceed. This is the same warning you'd
see with tools like Rufus, Ventoy, or HWiNFO portable.
```

### "How is this different from CCleaner?"

```
A few key differences:
- Free with no upsells (CCleaner pushes Pro on every screen)
- Zero internet/telemetry (CCleaner was caught bundling Avast telemetry)
- 338 KB single EXE vs 42+ MB installer
- Open source (you can read every line of code)
- 21 critical services are hardcoded as protected (can't brick your system)
- Every registry change creates a .reg backup automatically
```
