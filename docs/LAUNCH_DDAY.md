## HOTFIX PROTOKOLU (Bug Geldiginde)

```
1. Issue'yu oku → Tekrarlanabilir mi?
   ├── HAYIR → "Can you provide logs?" etiketi + yanit
   └── EVET → Devam ↓

2. Ciddiyeti belirle:
   ├── KRITIK (crash/veri kaybi) → 2 saat icinde fix
   ├── YUKSEK (modul calismıyor) → 24 saat icinde fix
   └── DUSUK (gorsel/kozmetik) → Sonraki surumde fix

3. Fix workflow:
   a. Yeni branch: git checkout -b hotfix/issue-XX
   b. Fix yap + test et (Win10 + Win11)
   c. Commit: "fix: [Module X] description (#XX)"
   d. Tag: git tag v5.0.1
   e. Push: git push origin v5.0.1
   f. CI/CD otomatik build + release
   g. Issue'ya yanit: "Fixed in v5.0.1 — please update"
   h. Reddit/PH'de guncelleme yorumu yaz

4. Kesinlikle YAPMA:
   ✗ Panige kapilma — her yazilimda bug olur
   ✗ Issue'yu silme veya gizleme
   ✗ "Works on my machine" deme
   ✗ Bug'i fix etmeden issue'yu kapatma
```

### "Why does SmartScreen warn me?"

```
SmartScreen warns about any app without an EV Code Signing Certificate ($400+/year).
As a free, open-source project, we don't have one — that's the only reason for the
warning. Click "More info" → "Run anyway" to proceed. This is the same warning you'd
see with tools like Rufus, Ventoy, or HWiNFO portable.
```
